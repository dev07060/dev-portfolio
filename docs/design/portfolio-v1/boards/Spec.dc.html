0. 전제

  • 기준 코드: main의 커밋 3576ca8. 작업 트리의 미커밋 변경은 쓰지 않습니다(사용자 지시). 폐기 여부는 '13. 열린 결정' 1번.
  • 적용 범위: /와 /freelancer가 같은 Portfolio 컴포넌트를 씁니다. 새 구조는 두 경로에 모두 적용하고, 차이는 config 문구로만 둡니다. freelancer는 resumeUrl이 없으므로 이력서 버튼과 링크를 모두 숨깁니다.
  • 한 섹션 = 한 화면: 보드는 1440×900 한 화면을 한 섹션으로 그렸습니다. 구현은 min-height: 100svh, 콘텐츠 세로 가운데 정렬. 고정 height는 금지(콘텐츠가 길면 섹션이 늘어나야 함).
  • 스크롤: scroll-snap과 섹션 진입 애니메이션은 넣지 않습니다. 움직임은 히어로 검색과 사례 #1 탭 두 곳에만 있습니다.
  • 금지: 카드 박스, chip, 구분선, 섹션 번호 라벨(예: '01 / 검색 코어'), 진행 번호(예: '02 / 06'). 박스 형태는 히어로 검색 패널 하나만 예외입니다.

7. 사례 #1 · Flutter 공개 패키지 (#case-01)

  • 제목은 'Flutter 공개 패키지'이고, 패키지명 mobile_rag_engine은 리드 문장 안의 일반 텍스트입니다(굵게나 mono로 바꾸지 않음, 사용자 편집 결과).
