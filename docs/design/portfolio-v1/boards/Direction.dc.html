섹션 하나가 화면 하나를 채우고, 화면마다 메시지도 하나입니다. 그래서 6개 섹션을 모두 한 화면 높이로 맞추고, 각 화면에 제목과 리드 문장 하나만 크게 둡니다.

Linearlinear.app ↗

어두운 바탕 하나 위에 제품 화면을 크게 올립니다. 바탕색은 바꾸지 않고, 밝은 앱 스크린샷이 각 화면의 주인공이 됩니다.

Raycastraycast.com ↗

제품 UI 자체가 히어로입니다. 히어로의 '포트폴리오 검색' UI는 결과 3건이 곧 사례 목차입니다.

2차 안에서 버린 것

섹션마다 다른 배경색: 검정, 파랑, 녹색, 회색, 노랑이 번갈아 나와 정신없었습니다. 이제 바탕은 하나이고, 섹션은 화면 높이로 나눕니다.

규칙
  1. 섹션 하나는 화면 하나(100svh)입니다. 콘텐츠가 한 화면을 넘으면 덜어냅니다.
  2. 바탕은 같은 차콜 계열 안에서 섹션마다 명도와 온도만 살짝 바꿉니다. 경력 #232427, 사례 #1 #292D34(차가운), #2 #312F2B(따뜻한), #3 #2A2F2B(녹색 기운).
  3. 글자 위계는 6단계입니다. 이름 120 → 섹션 제목 60 → 소제목 34 → 리드 20 → 본문 15–16 → 라벨 13–14.
  4. 노랑은 검색 하이라이트, 출처 있는 수치, 주요 버튼에만 씁니다.
  5. 비주얼은 실제 앱 화면입니다. 카드·chip·구분선은 쓰지 않습니다.
