Easy Contract Viewer

검색과 AI 요약의 결과를 언제나 PDF 원문의 정확한 근거 위치로 되돌립니다.

핵심 기능
온디바이스 약관 검색약관 PDF를 서버로 보내지 않고 기기 안에서 조항 단위로 찾습니다.
원문 근거 하이라이트검색·요약 결과에서 PDF의 정확한 근거 영역으로 바로 이동합니다.
동의 기반 AI 요약사용자가 동의할 때만 요약하고, 서버를 못 쓰면 로컬로 대체합니다.
비용이 통제되는 요약 서버요청 서명, 사용 한도, 예산 상한, 중복 요청 병합으로 남용을 막습니다.
사용 기술 Flutter · Riverpod · pdfrx · Python · FastAPI · Redis
프로젝트 사례 #3

Swifty-law

LLM이 검색된 공식 법령 근거 안에서만 답하도록 만든 인용 기반 검색 엔진.
